## 🌟 About This Repository

Welcome to my **LeetCode Problem of the Day (POTD)** repository! 🎉 

Starting from **June 9, 2026**, this repository serves as my daily coding journal. It’s not just a dump of raw code; it is a carefully curated collection of optimal solutions designed to help both me and you understand the *how* and *why* behind complex algorithms.

Whether you are preparing for FAANG interviews, brushing up on your data structures, or just love a good daily puzzle, you've found the right place! 💡

---

## 🔥 What Makes This Repo Different?

I believe that code should teach. That’s why every single file in this repository comes with:

* **🧩 Clean Code:** Highly readable, production-level code with optimal time ($O(N)$) and space complexities.
* **📖 In-Depth Explanations:** Heavy, detailed comments right inside the code files. No need to hunt for explanations—the logic, intuition, and edge cases are explained right next to the lines of code.
* **🛠️ Multiple Approaches:** Where applicable, I discuss the journey from Brute Force $\rightarrow$ Optimal Solution.
